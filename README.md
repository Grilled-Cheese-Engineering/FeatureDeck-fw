# FeatureDeck

This is a board designed to assist with programming showfiles in GrandMA3 by allowing the user to fine tune encoder values. The board comes with 5 rotary encoders and 3 extra buttons (with hot swap sockets). The board outputs MIDI to the host computer which also allows for compatibility with software other than GrandMA3.
